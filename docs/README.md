# DocGate 文档总览

## 当前决策

- 工作名：DocGate。
- 第一版用户：独立工作的 AI 重度使用者。
- 第一版对象：本地 UTF-8 Markdown 文件。
- 核心闭环：批注 → 结构化修改任务 → Agent 修改 → 真实 Diff 取证 → 逐任务验收 → 仅退回未通过任务。
- 差异化：不解决“怎样在文档上写意见”，解决“Agent 是否按每条意见正确完成修改”。
- 上游策略：通过适配器复用 Plannotator，不 fork、不复制其批注 UI。
- 第一阶段不做：团队、账号、协作、云端分享、Word/PDF、任意 HTML、通用文档编辑器、自动替用户最终验收。

## 文档优先级

出现冲突时按以下优先级处理：

1. 安全、隐私、可恢复、真实验收等强制底线：`AI产品Vibe Coding通用技术栈手册.md`。
2. 产品行为与范围：[新版 MVP PRD](01-产品需求文档-DocGate-MVP.md)。
3. 当前阶段实现约束：[第一阶段技术开发文档](03-第一阶段技术开发文档.md)。
4. 字段、状态与接口细节：[数据协议与状态机](04-数据协议与状态机.md)。
5. 测试数据和通过门槛：[测试与验收方案](05-测试与验收方案.md)。

根目录旧版 `AI文档处理中间件PRD.md` 及三个 HTML 文件是历史方案，不是 MVP 开发依据。其中团队、访客分享、账号、权限、导出和 SaaS 架构均已暂缓。

## 阶段路线

| 阶段 | 目标 | 进入条件 |
| --- | --- | --- |
| 第 1 阶段 | 跑通一个真实 Markdown 文件、至少 5 条意见的逐任务验收闭环 | 当前即可开始 |
| 第 2 阶段 | 增强 Markdown AST 结构检查、定位稳定性与可选语义验证 | 第 1 阶段人工验收通过 |
| 第 3 阶段 | CLI 分发、安装体验、更多 Agent/批注器适配 | 第 1 阶段有重复使用证据 |
| 后续探索 | 团队、云端、更多格式 | 有明确用户需求后再立项 |

## 开工入口

复制 [Goal 模式开发提示词](06-Goal模式开发提示词.md) 中的完整提示词启动开发。Goal 只允许实现第 1 阶段，不得提前建设后续范围。
